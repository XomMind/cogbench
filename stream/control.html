Cogbench · live parameters

RUN —
Start/Restart use the model selected below, plus these. Auto-revive covers the harness falling over: the agent comes back on the same episode five seconds after a crash. Loop episodes covers the bot dying: when a run plays itself out, Cogmind is relaunched on a new seed and the agent starts again. Neither fights a Stop you asked for.






  
TWITCH CHAT WINDOW
                   10 min

  
  
How far back the model is shown chat. Bigger window =
    more prompt = more prompt-processing time per decision.






  
CHAT MESSAGE CAP
                   20

  
  
Hard cap on lines, whatever the window holds. Repeated
    messages collapse to one before this applies.
